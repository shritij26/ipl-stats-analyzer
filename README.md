# 🏏 IPL Stats Analyzer — Cricket + Code + Coffee ☕

Welcome to the **IPL Stats Analyzer** — a Python-powered data exploration tool that dives deep into IPL matches using **pandas**, a bit of logic, and a lot of cricket love ❤️

> ⚠️ Note: This is one of my **first Python + Pandas projects**, and I’m continuously learning and improving. Feedback is welcome!

---
## Features

Explore key IPL insights with this interactive tool:

1. 🏏 **Top Run Getters** – See the top 10 batsmen across seasons.

2. 🏆 **Most Successful Teams** – Identify which teams have won the most matches.

3. ⚔️ **Head-to-Head Stats** – Compare any two teams’ full match history.

4. 👥 **Batsman vs Bowler** – Check how a batsman fares against a specific bowler.

5. 🔮 **Win Predictor** – Predict match outcomes using smart weighted logic based on head-to-head, recent form, and toss results.

6. 🎯 **Player vs Team Analysis** – Analyze a player's recent and career performance against any specific team.
